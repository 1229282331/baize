# baize 移动底盘

本项目为搭载机械臂的四轮灵风小车开发 STM32 底盘固件和上位机接口。上位机通过 USB 一次下发四轮目标角速度。底盘独立调速，返回编码器反馈、电源电压和驱动状态，并单独上报 MPU6050 的三轴加速度和三轴角速度。姿态融合由上位机负责，机械臂使用自己的硬件后端。

**当前交付状态（2026-11-22）**　车上运行空载 v1 候选固件。独立看门狗已在四轮架空点动时通过主循环卡住和 HardFault 复位试验。Windows 和 Linux 的独立 C++ 程序都经 SWD 测试通道完成了给速、读取轮状态和 IMU、停机及重新连接。空载地面速度范围、停距和真实 CH340 收发仍待验收。[下载候选固件、工具和回退包](docs/measurements/2026-11-22-v1-rc.zip) · [实测记录](docs/bringup-and-acceptance.md#空载-v1-候选版的台架记录) · [独立接入示例](examples/chassis/)

**四轮调速（2026-11-22）**　车上常规固件每 5 ms 用编码器闭环调速，采用 PI 加摩擦和速度前馈。四轮架空时，持续平稳转动的建议下限为 **0.35 rad/s**（约 3.3 转/分）。另用 1 ms 低速 PI 做架空对照，在 0.10 rad/s 的 32 个轮次中均能连续转动，0.20 rad/s 的 32 个轮次全部达到平稳标准。这一低速方案的 PWM 调节幅度更大，空载落地与装臂后分别复测。[常规固件的轮速下限](docs/bringup-and-acceptance.md#架空低速下限与微分对照) · [1 ms 调速实测](docs/bringup-and-acceptance.md#低速-pi-的-1-ms-实车对照)

架空单轮给 ±0.50 rad/s 时，达到目标 90% 的中位时间从 256.5 ms 缩至 27 ms，最差峰值超调从 24.0% 降至 11.8%。四轮同时给 ±2.00 rad/s 时，各轮末 100 ms 的平均轮速幅值为 1.993～2.008 rad/s。停止续发后 151 ms，板端撤销使能并将四路输出归中。车身轮位和朝前滚动方向待实物核对。[架空调参、对比曲线与原始数据](docs/bringup-and-acceptance.md#四轮架空调参复验)

已装的 GY-521 输出独立六轴帧，实测 49.92 Hz。IMU 读失败与就绪信号中断期间，四轮状态持续按 20 ms 上报。Windows 和 Linux 的 `baize-monitor` 可同时记录两路 CSV，并支持限时点动。真实 USB 收发待 A–A 数据线到位后验收。[工具用法与实测记录](docs/bringup-and-acceptance.md)

**上位机（2026-11-22）**　C/C++ 应用可直接链接 `baize_host`，与联调工具共用串口、编解码和启停握手。会话收到“未使能、主动停机”的新反馈后允许请求使能。轮反馈有效期按最近的新样本计算。[上层接入方法](docs/base-interface.md#上位机-c-库)

## 本期交付

| 交付物 | 使用方式 |
| --- | --- |
| STM32 固件与可复现的构建配置 | 从源码生成与发布版本对应的固件，通过 SWD 下载和调试。 |
| 独立的 USB 串口联调工具 | 在电脑上使能、停机、给定四轮速度，查看并记录轮状态、电压和带采样时间的六轴数据。手柄如需使用，接在上位机，沿同一条 USB 链路发指令。 |
| 底盘接口说明与 ROS 2 映射 | 普通程序可直接接入。本期提供四轮关节和 IMU 消息的映射。未来采用 `ros2_control` 时交付可运行的底盘插件并做 Linux 联调。 |
| 标定记录与可回退的发布版本 | 每个稳定版本配套固件、工具、协议版本、实测参数和复测方法。 |

## 实施计划与验收

| 阶段 | 完成条件 |
| --- | --- |
| 设计与工程基线 | 确定职责、轮序、协议及故障恢复语义。固定工具版本，从干净工作目录构建固件，并验证现有烧录器的 SWD 连接、下载校验和断点调试。 |
| 固件与主机工具 | 完成四轮调速、启停保护、电压反馈和可选 IMU 遥测。用协议向量核对收发，覆盖计数回绕、超时、传感器缺失和恢复。 |
| 整车验证与标定 | 架空低速点动核对轮序和正方向，验证 IMU 安装轴向及断线、重连、复位。空载先记录低速跟踪、直行、转向误差和停稳距离。装臂后在实际载荷与姿态下复测。 |
| 交付与维护 | 用独立工具复现一次完整的控制、测量、停机和恢复过程。将固件、标定参数、接口说明及验收结果关联到同一版本，验证能重新构建并回退到已验版本。 |
